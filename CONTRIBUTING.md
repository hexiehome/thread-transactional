# Contributing

Thanks for improving this teaching demo.

## Development Flow

1. Fork and create a feature branch.
2. Run tests locally:
   - `mvn test`
3. Keep changes scoped to one topic (coordination logic, scenario coverage, or docs).
4. Update README when behavior or API changes.
5. Open a PR with:
   - What changed
   - Why it helps teaching clarity
   - How it was verified

## Suggested Contribution Topics

- New deterministic scenarios for transaction behavior.
- Better observability around decision stages.
- Additional tests for failure and timeout edges.
- Documentation improvements and diagram clarity.
